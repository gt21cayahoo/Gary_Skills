- [Gmail Triage](gmail-triage/SKILL.md) — connector-based Gmail Inbox triage with durable Keep/Bulk sender rules, recoverable Spam moves, exact-ID verification, dated completion reports, and consolidated unresolved reviews. GitHub is the central source library for these skills. It is not the scheduler. Each skill's neutral core defines the work; provider adapters explain how to install and schedule it in supported environments such as ChatGPT/Codex, Claude Cowork, Perplexity Computer, or another compatible agent.
